# 中转站监控面板 · 使用说明

> 地址：**http://127.0.0.1:8788**
> ⚠️ 别开 `dashboard.html`（那是旧的静态快照，没有刷新按钮，已淘汰）

---

## 怎么启动

面板是个**本地小服务**，得先跑起来才能访问：

```powershell
cd "D:\Hermes works\proxy_monitor"
python panel.py --port 8788
```

启动后浏览器打开 **http://127.0.0.1:8788**。

> 💡 加了 `--open` 会自动弹浏览器：`python panel.py --open`

**关掉命令行窗口 = 面板停止**（数据不会丢，都在 `store.db` 里）。

## 页面功能

### 顶部：⟳ 立即刷新

| 按钮 | 作用 |
|---|---|
| **⟳ 立即刷新** | 马上去站方抓一次最新数据（约 43 KB）。完成后会提示"新增 N 条" |

**平时不用管它** —— 后台有个守护进程每 5 分钟自动采一次。这个按钮是**你想立刻看最新数据时**用的。

页面**每 3 秒自动重读本地数据**，所以你盯着看时数字是"活"的 —— 但那只是读本地库，**不产生任何网络流量**。只有点刷新才真的联网。

### 第一块：今日

| 行 | 含义 |
|---|---|
| **大数字 ¥x.xxxxxx** | 今天花了多少钱（含智能审批）|
| 请求合计 | 业务 N 次 + 审批 M 次 |
| 其中审批花费 | 智能审批单独花了多少、占总花费比例 |
| 缓存命中 / 未命中 | token 数 |
| 整体命中率 / 业务命中率 | **整体**含智能审批（会拉低）；**业务**只算真实对话，更准 |

### 第二块：累计

从第一次采集到现在的总量：请求次数、总花费、套餐余量 / 余额。

### 第三块：按对话

**这是最有价值的表** —— 把站方流水按时间归集到具体对话：

| 列 | 含义 |
|---|---|
| 会话 | 会话 ID（跟 Hermes 里的对话对应）|
| 请求 / 未命中 / 缓存命中 | 该对话的 token 明细 |
| 命中率 | 该对话的缓存表现 |
| 花费¥ | 该对话花了多少钱 |
| **置信** | 归集可信度（1.00 = 高，0.50 = 时间上不够确定）|
| 最后活动 | 该对话最后一次请求时间 |

> 用途：看哪个对话"烧钱"、哪个对话缓存没吃上（比如 subagent 会话命中率通常很低）。

### 第四块：按日明细

每天一行，**命中率只算业务请求（已剔除智能审批）**，避免被短请求拉低。

## 数据多久更新一次

| 层 | 频率 | 说明 |
|---|---|---|
| 后台自动采集 | **5 分钟** | 守护进程干的事 |
| 页面读本地 | **3 秒** | 只读本地库，零流量 |
| 手动刷新 | 你点才跑 | 一次约 43 KB |

**流量账**：5 分钟一轮 = 每天约 12 MB、每月 350 MB。手动刷新一次 43 KB。

## 数字怎么算出来的

```
金额（元） = quota ÷ 500000
```

`quota` 是站方返回的扣费额度，**500000 是换算系数**（在 `sites.json` 的 `quota_per_cny`，可改）。

**为什么是这个数**：站方使用记录页显示的官方单价是 `¥0.06 / ¥0.24/M`（输入/输出，元每百万 token），
单条记录验算 `quota ÷ 500000` 与之**差 1.0 倍**，即完全吻合。

**命中率**：
```
业务命中率 = 缓存命中 ÷ (缓存命中 + 未命中)     ← 只看真实对话
整体命中率 = 把智能审批也算进去                  ← 会偏低
```

**智能审批**是什么：Hermes 每次工具调用前的安全审查。特征很明显 —— 输入 330~850、**输出恒为 3**、**无缓存**、非流式、耗时 1~2 秒。它天然吃不到缓存，所以要单独剔除。

## 跟站方网页对不上怎么办

**先看时间** —— 网页是**快照**，你打开那一刻的数字跟面板可能差几分钟。实测正常差异在 **2% 以内**。

**差得多的话，按顺序查**：

1. **该站有几个 key？** 站方网页统计是**账号级**（所有 key 汇总），我只采配置里有的 key。
   用 `python find_keys.py d1api.xin` 查，或去站方网页的「API 密钥」页数一下。
   有没配进来的 → 加进 `sites.json` 的 `extra_keys`。

2. **时间范围对不对？** 网页默认可能是「最近 24 小时」而非「自然日」。

3. **quota 系数对不对？** 见上面的换算说明。

## 常见问题

**Q：页面打不开？**
A：面板服务没跑。`python panel.py --port 8788`。或者端口被占了，换 `--port 8789`。

**Q：点了刷新没反应？**
A：正常要等 5~10 秒（要联网抓两个站）。看右上角提示。

**Q：改动代码后没生效？**
A：**必须重启面板进程**。Python 服务不会热加载，旧进程会继续用旧逻辑。

**Q：电脑重启后没了？**
A：是的，现在没配开机自启。要的话说一声。
