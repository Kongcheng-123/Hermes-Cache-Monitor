## 2026-10-09 — v1.3.0

### 一、悬浮窗界面重构

**完成的**
- 去掉系统标题栏，改成无边框 + Windows 11 原生圆角
- 最小化 / 退出移入右键菜单
- 右键菜单与三个子窗口（价格配置 / 提示注入 / 实付录入）统一深色
- 窗口四边四角可拖拽缩放，完整模式与精简模式各自记住自己的宽和高
- 右键菜单新增透明度滑块，最低 30%
- 精简模式改极简风：只显示命中率、缓存/未缓存 token、金额
- 新增「今日站点消费」，跟随当前对话所用的站点

**新装的**
- 顶部托盘菜单也能变深色
- 子窗口表格深色样式

**修的 bug**
- 拖动只能按在有文字的地方，且拖动位移会累计（快速拖动跑偏、甚至飞出屏幕）
- 拉伸窗口时尺寸没有上限，能拉到比屏幕还大
- 改了透明度后重新打开右键菜单会跳回 100%
- 双击切换模式实际被触发两次，等于没切
- 子窗口（价格配置 / 提示注入 / 实付录入）标题栏是白的
- 精简模式缩到最窄后切回完整模式再切回来，宽度会变大

### 二、站点用量归集自愈

**完成的**
- 归集改为按 API 地址的主域名识别站点
- 新增归集健康检查（今日归集率 + 认不出的地址清单）
- 面板顶部加状态条：正常显示 `✅ 用量归集正常 N/N`；异常时写明哪个地址没登记，并给「补登」按钮
- 面板新增「站点配置」页，站点地址、Provider、代理都能在网页上改

**修的 bug**
- 换中转站入口地址后，用量统计不上（本会话 64 条 → 修复后 399 条；今日归集率 47% → 100%）
- 加站表单里填的「备选地址」不生效（之前只写进备注文字，没落盘）

### 三、发布流程

**完成的**
- 发布同步清单补了 3 个漏同步的文件：`site_admin.py` / `site_delete.py` / `join_health.py`
- 脱敏规则补上 dshapi 的 provider 别名
- 发布验证脚本 `verify_share_exe.py` 扩了检查项，覆盖 v1.3.0 全部新功能

**修的 bug**
- 验证脚本查入口脚本的写法是错的（一直查不到），已改成正确写法
- 清掉 3 处历史泄漏：`docs/06`（新文件，2 处私有域名）、`docs/01` / `docs/04`（3 处明文 provider 别名）

### 四、版本号

`1.2.1` → `1.3.0`。补记 CHANGELOG 里缺失的 1.2.1 / 1.2.0 两段。

## 2026-10-05 — v1.2.0

**完成的**
- 让 `proxy_monitor/` 一起打进 exe，修复打包版站方功能失效
- exe 启动时优先复用本机已有的 `proxy_monitor/`，只在没有时才从内置释放
- spec 打包时自动剔除数据库 / 日志 / 个人配置，只带代码与 `.example` 模板
- spec 加依赖强校验：缺 `pystray` / `Pillow` / `uiautomation` / `comtypes` 直接报错退出
- 支持环境变量 `HERMES_CACHE_PM_DIR` 显式指定 `proxy_monitor` 目录

**修的 bug**
- 点「校准」报 `No module named 'session_join'`
- 点「打开网页看板」拉不起 `panel.py`，8788 端口无人监听、浏览器白页
- 误用空数据库导致校准算出 0

**产物**
```
dist/HermesCacheMonitor.exe     单文件分发
build/HermesCacheMonitor.spec   打包规范（自包含）
dist/README.md                  分发说明
```
