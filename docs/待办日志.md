### 1. 分发给别人的场景未实测

**背景**：这次修的自愈逻辑有两条分支：

- **复用分支** —— 本机有 `D:\Hermes works\proxy_monitor`，直接用它（**已实测**）
- **释放分支** —— 没有真实目录时，从 exe 内部释放一份到同级（**只做了逻辑推演，没真机跑过**）

**为什么要测**：发给朋友时走的是释放分支。万一有问题，对方拿到 exe 点校准就报错。

**怎么测**：找一个不含 `D:\Hermes works` 的路径（比如 `E:\test_hcm\`），
只放 exe 不放 `proxy_monitor`，跑起来看：

```bash
# 预期：exe 同级自动出现 proxy_monitor/，startup.log 记录"已释放 proxy_monitor 到 ..."
```

还要确认这个环境变量的优先级没写错：

```bash
set HERMES_CACHE_PM_DIR=E:\some\path\proxy_monitor
```
